## **✨ Funcionalidades Principais**  

### **👨‍🎓 Para Alunos**  
✅ **Acesso a cursos** conforme plano contratado  
✅ **Barra de progresso** e % de conclusão  
📥 **Download de materiais** (registrado automaticamente)  
✉️ **Caixa de entrada** para comunicação com professores  
👥 **Grupos exclusivos** (WhatsApp / Plataforma)  
🎤 **Mentorias online** (Planos Empreendedor e Startup)  
🚀 **Incubação de negócios** (Plano Startup)  

### **👨‍🏫 Para Professores**  
📊 **Acompanhamento de progresso** dos alunos  
📩 **Envio de mensagens e feedbacks**  
📚 **Upload de materiais e vídeos**  

### **👨‍💻 Para Administradores**  
⚙️ **Gerenciamento completo** de cursos, usuários e turmas  
📈 **Relatórios e métricas** de engajamento  
🔐 **Controle de acessos e permissões**

## **🛠 Como Executar o Projeto**  

### **1️⃣ Clone o repositório**  
```sh
git clone https://github.com/seu-usuario/inova-learn.git
cd inova-learn
```

### **2️⃣ Configure o Backend**  
```sh
cd server
yarn install  # ou npm install
cp .env.example .env  # Configure suas variáveis
yarn prisma migrate dev  # Crie o banco de dados
yarn dev  # Inicie o servidor
```

### **3️⃣ Configure o Frontend**  
```sh
cd ../client
yarn install  # ou npm install
cp .env.example .env  # Defina a URL da API
yarn dev  # Inicie o app React
```
